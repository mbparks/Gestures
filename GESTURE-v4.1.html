GESTURE Quick Start

v4.0 STABLE RELEASE

EASY

Record → Auto Interpret → Export. On phones, the canvas is home: use the floating RECORD control and bottom dock for Capture, Style, Library, Insights, and More.

ADVANCED

Use Instrument Focus to narrow the interface to Capture, Analyze, Interpret, Compose, or Output. RAW capture stays untouched; transforms, simplification, CROSS MAP, and style operations are non-destructive.

LIVE

Choose Pointer, Camera, or Sensor, enter LIVE, then press F for Performance View. Use [ and ] to switch Recipes, X to freeze, and C to clear.

FABRICATION

Plotter Mode provides physical dimensions, units, path order, travel optimization, estimated plot time, DXF, HPGL, and true-scale SVG.

PROJECT SAFETY

Autosave, recovery snapshots, undo/redo, state repair, JSON project export, and SVG metadata round trips protect editable motion data.
